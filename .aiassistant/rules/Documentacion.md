# Documentación de cambios

- Documentar cada cambio realizado indicando:
    - Archivo modificado.
    - Método o componente afectado.
    - Motivo del cambio.
    - Comportamiento anterior y nuevo.
    - Posibles impactos.
    - Pruebas realizadas.

- Agregar JavaDoc o esplicacion de uso a clases y métodos nuevos o modificados.
- Documentar endpoints con OpenAPI/Swagger.
- No agregar comentarios que solo repitan lo que hace el código.
- Actualizar el README ubicado sebastian-betancourt-g3/README.md cuando cambien la configuración, despliegue o variables de entorno.
- Al finalizar, presentar un resumen de cambios y pruebas ejecutadas.
